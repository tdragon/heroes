# Heroes Clone

A browser-based, single-player clone of a classic turn-based strategy game: adventure map
exploration, town building, creature armies, and tactical hex-grid battles against AI
opponents. All art is original placeholder art; mechanics only.

## Commands

- `npm run dev` — start dev server
- `npm run build` — typecheck + production build
- `npm test` — unit tests (Vitest)
- `npm run test:e2e` — browser tests (Playwright)
- `npm run check` — tsc + eslint + unit tests
