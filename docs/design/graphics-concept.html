Open Heroes · Visual Design Language · Concept I

Gilded Woodcut

The land is the parchment. Every piece upon it is a seal, stamped in ink and touched with gold.

I

The Creed

Six rules govern every asset, from a tuft of grass to an archangel. They exist so that fifty-one creatures, sixty-four buildings, and eighteen map objects can be drawn by many hands — or generated — and still feel like one game.

Rules of the Handfolio i
  • 1

    Silhouette first

    Every emblem must read as pure ink at 24 px. If the shadow doesn't say "griffin", no amount of detail will.

  • 2

    Ink holds everything

    One outline color — Peat Ink #241b16 — binds every sprite. Same relative stroke weight everywhere.

  • 3

    Three tones per material

    Base, shade, light. Flat fills, no gradients on pieces — shading is a shape, not a blur.

  • 4

    Terrain whispers, pieces speak

    The land is desaturated and low-contrast. Saturation and gold belong to the things you click.

  • 5

    Gold is earned

    Gold marks meaning: selection, tier, treasure, ownership. It is never decoration on the land.

  • 6

    One sun

    Light always falls from the upper-left. Shade shapes sit low-right — on every tile, token and tower.

Faction Triads

Castle

crimson · steel · gilt

Pikeman → Archangel. Polished metal, banners, white feathers. The most "civilized" geometry: verticals and symmetry.

Rampart

leaf · bark · gilt

Centaur → Gold Dragon. Curved, organic lines; wood and hide; gold reserved for the dragon and elven arrowheads.

Necropolis

bone · shade-violet · grave-green

Skeleton → Bone Dragon. Jagged, asymmetric, hollow shapes. The only faction whose accent is a sickly green, never gold.

The Pieces

Nine of the fifty-one creatures, three per faction, spanning tier 1 to tier 7 — enough to prove the grammar holds from a pikeman to a bone dragon. Each is a flat heraldic emblem: not a miniature painting, a mark.

Bestiary Emblems · 64 px gridfolio iv
The Seal · token anatomy
  • AParchment field — every creature sits on the same warm disc, so any emblem reads against any terrain, fog included.
  • BDouble ink ring — the woodcut frame; thick outer, hairline inner. Selection swaps the outer ring to Gilt Bright.
  • CTier pips — gilt diamonds, one to seven, replacing today's numeric badge. Countable at a glance, language-free.
  • DBanner notch — the only place ownership color appears (here: Blue). Neutral stacks wear grey. Creatures are never recolored.
  • ESame emblem everywhere — adventure seal, combat plinth, recruitment row, garrison list. One SVG per creature, four contexts.

VI

Vector or Raster?

Verdict: author 100% of game art as SVG. Hand-made raster is not required for anything. Raster appears only as a runtime optimization — and, optionally, for the existing painterly logo and a future menu backdrop.

The Casefolio vi

SVG — the source of truth

Adopted
  • Crisp at every zoom. The adventure map already scales tiles; vectors never blur on retina or zoom-out.
  • ~1–3 KB per sprite. The full ~230-asset set ships smaller than a single PNG spritesheet, and gzips brutally well.
  • Diffable & reviewable. Sprites live in git as text — PRs show real diffs, matching this repo's data-driven, zod-validated philosophy.
  • Parametric color. Banner notches use currentColor — four player colors from one file, no recolored copies.
  • Editable by hand or model. The flat woodcut style is deliberately path-friendly; every sprite on this page was written as text.

Raster — only where it earns it

Optional
  • Runtime atlas, not source. Drawing complex paths every frame is slow — rasterize each SVG once per zoom level into an offscreen ImageBitmap atlas at load, then blit.
  • The painterly exceptions. The existing Open Heroes logo stays a bitmap; a future main-menu backdrop may too. Neither is gameplay art.
  • Never needed for sprites. No terrain, unit, building or icon requires hand-painted texture in this language.
  • No text inside sprites. Glyphs rasterize differently across platforms; labels stay in canvas/DOM where the game already draws them.
Author

SVG symbols in git

src/assets/sprites/*.svg — one file per entity id (creature.griffin.svg), same id-keyed discipline as src/data/.

Load

Rasterize once

createImageBitmap() per sprite per zoom bucket (e.g. 32 / 64 / 96 px) at startup — milliseconds, off the hot path.

Render

Blit from atlas

A new SpritePainter implements the existing Painter interface — drawImage per tile/token. Core stays untouched; determinism unaffected.

Fallback

Tokens remain

Today's TokenPainter stays as the loading/error fallback and for entities without art yet — the swap is per-sprite, not all-or-nothing.
